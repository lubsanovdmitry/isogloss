# Isogloss

A seeded, deterministic simulation of a language family over a thousand years
on a procedural continent. Sound changes, word replacements and their
isoglosses spread hex to hex as waves; languages, the family tree and every
word's etymology emerge from that. See the [spec](docs/Isogloss%20—%20Language%20Evolution%20Simulator%20Spec.md),
the [implementation notes](docs/IMPLEMENTATION.md) and [what remains](docs/TODO.md).

Status: **M5 (campaign and storyteller)**: all five milestones of the spec. Phonology, lexicon, wave spread,
clustering, the shared-innovation tree, etymology traces, inflection with the
grammaticalization cycle, analogy and word order, meaning drift and homophony,
borrowing with loan strata, substrates and place names, polities, conquest,
trade routes, writing and standards, several families, scenario files, a
steering campaign, an optional AI storyteller (bring your own Anthropic API
key), the browser app and the CLI. Extensions are listed in docs/TODO.md.

## Run it

Requires Go 1.26+ and Node 22+.

```sh
make test                      # engine tests, sound-law fixtures, golden digests
make build                     # bin/isogloss

bin/isogloss run --seed 42 --ticks 40 --out run.json   # 1000 years; prints the tree
bin/isogloss run --scenario empire-collapse            # a starter scenario (or a YAML file)
bin/isogloss run --language latin                      # start from a real language (latin, pie,
                                                       #   proto-germanic, proto-austronesian)
bin/isogloss etym run.json water                       # trace 'water' in every language
bin/isogloss etym run.json say --form PST.3SG          # trace an inflected form
bin/isogloss grammar run.json                          # Markdown grammar sketches
bin/isogloss export --cldf out/ run.json               # CLDF Wordlist + true tree (Newick)
bin/isogloss sca testdata/sca/grimm-verner/rules.isg testdata/sca/grimm-verner/words.txt

cd web && npm install && cd ..
make web-dev                   # browser app with hot reload
make web                       # production build in web/dist
cd web && npm run e2e          # browser smoke test against web/dist (cached Playwright Chromium)
```

## Layout

| Path | What |
| --- | --- |
| `engine/` | Pure Go, no I/O; runs natively and as WASM ([rules](engine/README.md)) |
| `engine/phon` | Feature bundles, IPA, syllables, stress, repair |
| `engine/rules` | The sound-change rule language: parser and applier |
| `engine/tmpl` | ~70 sound-change templates instantiated per language |
| `engine/morph` | Grammatical slots and stages, paradigm cells, word-order parameters (WALS priors) |
| `engine/society`, `scenario` | Polities, routes, writing; scenario files and the eleven starters |
| `engine/contact` | Nativizing loans, borrowability, substrate languages, place names |
| `engine/lex`, `world`, `pop`, `history`, `sim` | Lexicon and paradigms, map, wave spread and clustering, innovations and traces, tick loop |
| `engine/render` | JSON, etymologies, comparative tables, correspondences, grammar sketches, parallel text, CLDF |
| `engine/data` | Tables generated by `cmd/datagen` from PHOIBLE, Concepticon, CLICS³, WALS, IE-CoR ([licences](data/LICENSES.md)) |
| `cmd/isogloss` | CLI |
| `wasm/` | Web Worker bridge |
| `web/` | Svelte app |
| `testdata/` | Sound-law fixtures and golden digests |
